# NUYE（ニュイェ）

**知識を、伝わるかたちに。** NUYEは、技術を学びたい人と伝えたい人のための記事プラットフォームです。文章だけでなく、図やコード、吹き出しを組み合わせて、自分らしい記事をつくれます。

[English version](./README.en.md)

## NUYEでできること

### 読む・探す

- 公開された記事を一覧から読めます。キーワードやタグで記事を検索できます。
- 記事の冒頭で要約を確認し、本文中のコードや図解、表、クイズを見ながら学べます。
- 読んだ記事は閲覧履歴に表示されるので、あとから読み返せます。
- テンプレートを選べば、「技術解説」「コードチュートリアル」「図解・まとめ」の構成からすぐに書き始められます。

### 書く・伝える

- ボタン操作のエディタで、見出し、本文、引用、リスト、表、コード、画像を組み合わせられます。Markdownを覚えなくても記事を書けます。
- 自由配置キャンバスにテキスト、吹き出し、図形、手書き、画像、コード、クイズを置き、移動やサイズ変更をしてレイアウトできます。キャンバス内のテキストはMarkdownにも対応しています。
- タイトル、概要、カテゴリ、タグ、カバー画像を設定し、プレビューで読者からの見え方を確認してから公開できます。
- 編集内容は自動保存されます。公開すると記事のURLが作成され、共有できます。

### 読んだ記事を活用する

- 記事ページからコメント、いいね、フォロー、保存、共有を試せます。
- 用語辞典の用語をマイページに保存できます。
- 記事のクイズは選択式と短答式に対応しています。

## はじめかた

1. 記事を読む場合は「記事を読む」、書く場合は「記事を書く」を選びます。
2. 新規登録またはログインすると、マイページから自分の記事や閲覧履歴、保存した用語を確認できます。
3. 新しい記事は、テンプレートを選ぶか、エディタで自由に作成します。プレビューを確認してから公開してください。

スマートフォンでは、ブラウザーの共有メニュー（iPhone/iPad）またはブラウザーのメニュー（Android）から「ホーム画面に追加」を選ぶと、NUYEのアイコンをホーム画面に追加できます。

## 保存とデモ機能について

Supabaseが接続されていない環境ではデモモードで動作し、アカウント、記事、閲覧履歴などのデータはそのブラウザー内に保存されます。別の端末やブラウザーとは共有されません。デモモードのデータを残したい場合は、同じブラウザーをお使いください。

Supabase接続時は、アカウント認証、記事と画像の保存を利用できます。一方、コメントはブラウザー内への保存で、いいね・フォロー・記事の保存・クイズの回答は現在デモ用の操作です。これらの操作は他の利用者との共有や、次回アクセス時の復元を保証しません。また、記事の要約と用語辞典は現在サンプル表示で、外部AIによる生成ではありません。

## 運営・開発者向け

ローカルで試すにはNode.jsを用意し、次を実行します。

```sh
npm install
npm run dev
```

Supabaseを使用する場合は、`.env.example`を参考に`.env.local`へ設定します。

```env
VITE_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
VITE_SUPABASE_ANON_KEY=YOUR_SUPABASE_ANON_KEY
```

Supabase DashboardのSQL Editorで`supabase/migrations/202611050001_initial_schema.sql`を実行してください。フロントエンドにはAnon Keyのみを設定し、Service Role Keyは設定しないでください。
